# Маленький секрет — инструкции проекта

Следуй постоянным пользовательским правилам чистоты. Для этого проекта действует явное постоянное разрешение пользователя на обычные commit и push в `main` репозитория `elizabeth445/gender1` после каждой успешно завершённой задачи на изменение сайта.

## GitHub workflow этого проекта

- `origin`: `https://github.com/elizabeth445/gender1.git` (SSH-эквивалент: `git@github.com:elizabeth445/gender1.git`), основная ветка — `main`. Не создавай другой удалённый репозиторий.
- После каждой правки сайта выполни очистку, проверку секретов, `npm run verify` и браузерную проверку затронутых сценариев. Затем проверь status, diff, staged diff, remote и ветку; создай понятный коммит только с нужными изменениями и сразу отправь его в `main`. Дополнительное подтверждение для этих обычных commit/push не требуется.
- Проверяй удалённый SHA после отправки. В ответе на русском кратко указывай изменения, результат проверок, результат push и SHA коммита.
- Если локальная Git-аутентификация недоступна, используй подключённый GitHub-плагин для отправки и затем безопасно синхронизируй локальную ветку с опубликованным коммитом.
- Сохраняй историю и чужие изменения. Не применяй force push и разрушительные Git-команды. При конфликтах, изменившейся удалённой истории или ошибках, мешающих безопасной отправке, сообщи о проблеме; не обходи защиту ветки.
- Это разрешение относится только к commit/push в указанный репозиторий. Deploy и автоматическую публикацию на хостинге не настраивай без отдельной команды.

## Устройство проекта

- React, TypeScript, Vite и GSAP; язык сайта — украинский. Данные события находятся в src/config.ts. Ответы RSVP и прогнозы хранятся локально в браузере.
- Устанавливай зависимости через npm ci, сохраняй package-lock.json. Для проверки используй npm run verify (lint, typecheck, Playwright, build). При отсутствии runtime в PATH: source ~/.codex/bin/frontend-env.sh.
- Playwright использует отдельный Chrome и локальный сервер 127.0.0.1:5186. Проверяй 320, 390, 768, 1024 и 1440 px, конверт/бант, touch-навигацию, прогноз, RSVP, календарь и reduced motion.
- Все четыре public/images/*.webp используются: бант и три размера изображения площадки через srcset. Не удаляй адаптивные варианты как дубликаты.
- output/, test-results/, playwright-report/, dist/ и *.tsbuildinfo генерируются; не добавляй их в Git. Источники визуального оформления хранятся в design.md.
- Развёртывание Vercel: Vite, npm run build, выход dist. Backend, секреты и переменные окружения этому frontend не требуются.
