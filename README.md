# Маленький секрет

Локальное интерактивное приглашение на украинском языке. React 19, TypeScript, Vite, GSAP 3 и ScrollTrigger. Шрифты Cormorant Garamond и Manrope хранятся в проектных зависимостях, сетевые font CDN не используются.

## Запуск

```sh
source ~/.codex/bin/frontend-env.sh
npm install
npm run dev -- --port 5186 --strictPort
```

Откройте [http://127.0.0.1:5186](http://127.0.0.1:5186). Можно также дважды щёлкнуть `start.command`.

## Детали события

Отредактируйте **`src/config.ts`**: имена, начало и окончание, часовой пояс, срок ответа, город, площадку и программу. Площадка — Forrest Club, Київ, просп. Литовський, 20а; адрес и ссылка карты проверены по официальному сайту ресторана. Текущая дата — 12 июня 2027 года, срок ответа — 5 июня. Дата задаётся ISO-строкой с корректным UTC-смещением: `2027-06-12T15:00:00+03:00`. `timeZone` используется для отображения даты и времени. Стабильный `id` сохраняет уже записанные ответы при переносе даты.

Адрес, `mapsUrl`, `venueUrl`, описание и `venuePhoto` находятся в конфигурации. Кнопка маршрута отображается при заполненном адресе. RSVP сохраняет ответы только в браузере.

## Возможности

- Конверт раскрывается последовательной GSAP-анимацией. Можно пропустить, закрыть Escape и повторить через кнопку внизу. Внутри диалога удерживается фокус, фоновая страница недоступна до закрытия.
- Прогноз сохраняется в `localStorage`; другую команду можно выбрать в любой момент. Выбранный шарик улетает вверх, повторный выбор корректно прерывает предыдущую анимацию. Общих результатов голосования нет.
- Непрерывная SVG-лента рисуется по мере прокрутки. На мобильных используется нативный скролл. Повторный layout после изменения формы корректирует траекторию.
- Таймер работает до момента начала события, после чего показывает состояние «день настав». Файл `.ics` содержит UTC-время, UTF-8, переносы CRLF, экранирование и свёртку строк по RFC 5545.
- RSVP проверяет обязательные поля, сохраняет ответ и пожелания, позволяет редактировать их после перезагрузки. При запрете хранилища показывает честное предупреждение.
- В режиме `prefers-reduced-motion` открытие мгновенное, входные и scroll-анимации выключены, всё содержимое доступно.

Ответы **не отправляются организаторам**. Базы данных и серверной части нет. Очистка хранилища браузера удаляет ответы. Реальный пол ребёнка не хранится в коде или конфигурации.

## Проверки

```sh
npm run verify
```

Playwright использует отдельный профиль Chrome. Набор покрывает 320, 390, 768, 1024 и 1440 px, открытие/повтор, клавиатуру, touch, прогноз, RSVP, ICS, отсчёт, reduced motion, недоступное хранилище, украинские глифы и axe. Скриншоты и отчёты создаются в игнорируемых `output/qa/` и `playwright-report/`; они не предназначены для Git.

Production-версия создаётся в `dist/`. Локальный предпросмотр: `npm run preview -- --port 5187 --strictPort`.

## Визуальные материалы

Арт-дирекция и источники: `design.md`. Бант в `public/images/satin-bow.webp` создан встроенным imagegen, исходный prompt сохранён в `design.md`; WebP с альфа-каналом занимает около 107 КБ. Фотография праздничной зоны предоставлена пользователем; варианты `forrest-celebration-*.webp` оптимизированы для разных экранов, композиция сохранена. Остальной декор — SVG/CSS.

В локальном режиме доступен Agentation для обратной связи по интерфейсу. Он отключается при запрете записи в хранилище браузера и не включается в production-сборку.

## Подготовка к Vercel

Используйте preset **Vite**, команду сборки `npm run build` и каталог результата `dist`. Зависимости воспроизводятся через `npm ci`; переменные окружения не требуются. Публикация выполняется только по явной команде пользователя. Перед ней выполните `npm run verify` и проверьте diff, файлы на секреты, remote и ветку.
